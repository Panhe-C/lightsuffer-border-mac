# Samples

Four synthetic photographs that show how the film borders look. They are **not
photographs**: every pixel is generated by a small program (a sky gradient, a
sun, a few layers of ridges and a little noise), so they contain no personal
data and no third party rights.

**License: CC0 1.0 (public domain).** Do whatever you want with them.

| file | size | what it shows |
| --- | --- | --- |
| `landscape.jpg` | 1800 x 1200 | a warm sunset over three ridges (3:2) |
| `portrait.jpg` | 1200 x 1800 | cold hills in the fog (2:3) |
| `square.jpg` | 1500 x 1500 | a blue hour with a pale sun and a lake (1:1) |
| `wide.jpg` | 1920 x 1080 | a panoramic sunset (16:9) |

All of them are JPEG (quality 88, progressive) and carry a small EXIF block
(Make `Light Suffer Frame`, Model `Synthetic Sample Camera`, a date and the
orientation 1), so that the import of the app and the export can be tested with
a real metadata block.

## How they were made

The pictures are generated with Python (numpy + Pillow):

1. a vertical sky gradient with three colours,
2. a sun (a disc and a halo),
3. three or four ridge layers; the profile of a layer is fractal value noise,
   the distant layers are mixed with the colour of the haze and the misty
   picture has a fog band above every ridge,
4. a little Gaussian noise (about one level) so that the JPEG encoder has
   something to work with.

The files are small (90 - 105 kB), so that a batch of exports stays fast in the
continuous integration.

## Using them

```
frame-cli render --style film35 --text "KODAK PORTRA 400" samples/landscape.jpg out/
frame-cli render --style film120 samples out/          # a whole folder
```

They replace each other freely: they are only pictures, the app never touches
the original file.
